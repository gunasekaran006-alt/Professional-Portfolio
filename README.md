# 🧑‍💻 Gunasekaran S | Portfolio Website

A modern, dark-themed, fully responsive personal portfolio website built with **HTML5, CSS3, Bootstrap 5, and vanilla JavaScript** — showcasing my journey from 12+ years of business experience into **AI-enhanced MERN Full Stack Development**.

🔗 **Live Demo:** https://my-professionalportfolio.netlify.app

---

## 📌 About

This portfolio highlights my technical skills, projects, certifications, professional experience, and career transition into software engineering. It combines a clean developer-focused UI with subtle animations and interactive components to present my work in a polished, recruiter-friendly format.

---

## ✨ Features

- ⚡ **Typing Effect Hero Section** – dynamically cycles through job roles
- 🎯 **Scroll Reveal Animations** – sections fade/slide in using `IntersectionObserver`
- 🧭 **Active Navigation Highlighting** – navbar links auto-highlight based on scroll position
- 🏆 **Certificate Gallery Modal** – Bootstrap modal showcasing all verified certifications in one place
- 📱 **Fully Responsive** – optimized for desktop, tablet, and mobile
- ⬆️ **Back-to-Top Button** – smooth scroll-to-top on click
- 📄 **Resume Download** – one-click resume download button
- 🔒 **Skills organized by domain** – Frontend, Backend, Security, AI/Automation, Multi-domain foundations

## 🚀 Getting Started

### Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/gunasekaran006-alt/Professional-Portfolio.git
   ```
2. Navigate into the project folder
   ```bash
   cd <Professional-Portfolio>
   ```
3. Open `index.html` directly in your browser, or serve it with a local server (recommended, for the modal/asset paths to resolve correctly):
   ```bash
   npx serve .
   ```

### Deploy

This is a static site — deploy it for free on any of these:
- **Netlify** – drag & drop the folder or connect the GitHub repo
- **Vercel** – import the repo, no build step needed
- **GitHub Pages** – enable Pages in repo Settings → Pages → deploy from `main` branch
